٤. نواقص في PDF — لإرسالها لمطور الباك

فجوة ١ — animal_in_car: false لا يظهر السؤال

مفتاحBodyPDFالحالة
animal_in_car الموبايل يرسل دائماً true أو false عند false يختفي «Fanns djur i bilen?» Missing

السبب: في getYesNoQuestions → getBoolValue يُستخدم || بدل ??، فالقيمة المنطقية false تُعامل كـ «غير مجاب». 

// في getBoolValue — استبدل || بـ ?? عند قراءة المفاتيح:
val = reportData[key]
   ?? reportData.report?.[key]
   ?? reportData.oneAccident?.[key]
   ?? …;

التحقق: S1 — انقل Fanns djur i bilen? من knownMissing إلى mustInclude.

فجوة ٢ — animal_in_car_description لا يُطبع أبداً

مفتاحBodyPDFالحالة
animal_in_car_description وصف الحيوان عند Ja لا يظهر في مسار PDFKit Missing

الموجود في قالب EJS القديم فقط؛ generatePdf.js لا يضيف الحقل إلى Kompletterande.

// أضف بعد صف animal_in_car عندما تكون القيمة true:
{ label: 'Beskrivning av djur i bilen:', value: getFieldValue('animal_in_car_description') }

التحقق: S3 / S12 — انقل توكن الوصف من knownMissing إلى mustInclude.

٥. ملاحظات (ليست فجوات باك)

  • لا بَرْج: الواجهة لا تسأل «Har fordonet behövt bärgas?» ولا يُرسل car_towed — متوقع.
  • damage_part: N/A: الموبايل يرسل N/A حتى بدون ضرر خارجي فيظهر «Skadad del: N/A» — سلوك موبايل.
  • partner_outside / egendom_owner: aliases قديمة؛ الموبايل يرسل المفاتيح الجديدة بالتوازي والـ PDF يعتمد عليها.
