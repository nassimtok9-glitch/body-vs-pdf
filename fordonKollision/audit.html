بلاغات جاهزة للنسخ

Report type: kollision (Fordon)
Evidence: code-derived audit, 2026-08-19

High priority parity gaps:
1. "Annat" free text can be stored in accident_type instead of
   accident_type=other + accident_type_other, so the PDF shows no matching
   circumstance and does not print the free text.
2. Personskador PDF reads partner[0] only although partner[] stores all rows.
3. Mobile collects animal-in-car answer/description but buildKollisionFields()
   sends neither animal_in_car nor animal_in_car_description.
4. Signature PNG is stored, but PDF signature image rendering is disabled.

Contract rejection risks:
- towing=true without towing_location
- witness=true with a witness missing name/email/person_number

Redundant payload:
- partner_outside[] duplicates external_person_injuries[]
- egendom_owner[] duplicates third_party_property_damages[]

التحقق

  • post_kollision_test.dart تم تشغيله ونجح بالكامل؛ حالات Fordon Kollision داخله نجحت.
  • اختبارات Backend/PDF لم تُشغّل في هذه الجلسة لأن node_modules غير موجود.
  • توجد fixtures واختبارات PDF في الباك تغطي المسار الغني لمركبتين والإصابات والشهود.
  • لا توجد automated body-to-PDF matrix شاملة لكل الفروع المذكورة.
