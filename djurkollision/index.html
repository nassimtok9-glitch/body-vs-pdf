٤. نواقص في PDF — لإرسالها لمطور الباك

فجوة ١ — car_towed لا يظهر «Bil bärgad?»

مفتاح APIBodyPDFالحالةملاحظة
car_towed true / false من الموبايل دائماً لا يظهر سؤال Bil bärgad? لـ animal Missing في getYesNoQuestions() لا يوجد فرع animal لـ car_towed (بعكس brand/kollision/…). القائمة العامة تستخدم مفتاح towing وgetBoolValue('towing') لا يقرأ car_towed.

الملف: IH-backend/src/helpers/generatePdf.js — الدوال getYesNoQuestions و getBoolValue.

// المطلوب في getYesNoQuestions:
} else if (reportType === 'animal') {
  questions.push({ key: 'car_towed', label: 'Bil bärgad?' });
}

// وفي getBoolValue عند key === 'towing' إن كانت القيمة فارغة:
val = reportData.car_towed
   ?? reportData.report?.car_towed
   ?? reportData.animal?.car_towed;

// وعند قراءة المفاتيح العامة أضف أيضاً:
reportData.animal?.[key]

التحقق بعد الإصلاح: ظهور Bil bärgad? في S1 / S6 / S7 داخل animalPdfParity.test.js (انقل التوكن من knownMissing إلى mustInclude).

فجوة ٢ — إصابات خارجية تحت animal.* فقط

مفتاح APIBodyPDFالحالةملاحظة
animal.external_person_injuries_exist قد تبقى على مستند التفصيل فقط قبل الدمج الكامل القسم فارغ Missing drawSkadorCyklistFotgangareSection يقرأ root / report / oneAccident فقط — لا يقرأ animal.*
animal.external_person_injuries[] الاسم / الإصابة / العنوان لا يظهر Missing نفس الدالة
